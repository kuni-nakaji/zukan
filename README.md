# もののなまえ はじまり図鑑 ⏰🚀
〜タイムマシンで たんけん！〜

小学1年生（6〜7歳）向けの、身近なものの名前の起源・歴史・豆知識をグラフィカルに学べるWebアプリケーションです。
サーバー不要、ブラウザで開くだけですぐに動きます。

## ✨ とくちょう

- 🎒 **身近な20語のプリセット図鑑**: ランドセル、パン、ポスト、鉛筆、自転車、ピアノ、カレーなど。
- 🌀 **タイムマシン演出**: 過去の時代へタイムスリップするワープアニメーション。
- ⏳ **むかしといまの変遷タイムライン**: 昔の姿・途中の姿・今の姿を比較。
- 🎯 **たのしい3択クイズ**: 正解すると紙吹雪＆ファンファーレが鳴る！
- 🔊 **やさしい音声読み上げ**: 小学1年生が聞き取りやすい速度で読み上げ。
- 🎙️ **音声入力対応**: マイクに向かって話すだけで検索可能。
- 🤖 **Gemini API連携**: 右上の「せってい」からAPIキーを入力すると、20語以外のどんな言葉でもAIが小学1年生向けに図鑑データを自動生成。
- 👨‍👩‍👧 **おうちのひと向け解説**: 保護者が一緒に読んで補足できる歴史・背景メモ付き。

## 🚀 つかいかた

### 1. そのままブラウザで開く
リポジトリ内の `index.html` をダブルクリックしてブラウザ（Chrome / Safari / Edge）で開くだけです。

### 2. GitHub Pages で公開する場合
リポジトリの **Settings** > **Pages** > Branch を `main` / `root` に設定して保存すると、スマホやタブレットからいつでも遊べるWebサイトとして無料公開されます。
